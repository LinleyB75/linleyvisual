# linleyb.com

Linley Bignoux, photographer, underwater photographer and teacher: landscape and travel, street and everyday life, nature and wildlife, and underwater.

Live site: https://linleyb.com

## Structure
- `index.html`: homepage (hero, featured photos, about)
- `gallery.html`: all photos, with category buttons, grid size switch, slideshow and full-screen viewer
- `privacy.html`, `404.html`
- `site.css`: the styles for every page
- `site.js`: menu, light/dark switch, email links, gallery buttons, grid size and photo viewer
- `consent.js`: cookie banner (Google Analytics only loads after Accept)
- `images/`: header photo, hero self-portrait, the two About photos, icons, share picture
- `images/photos/`: the gallery photos
- `sitemap.xml`, `robots.txt`, `CNAME`

Hosted on GitHub Pages.
