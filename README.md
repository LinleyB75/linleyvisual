# Linley Bignoux | Email Developer Portfolio

Welcome to the source code repository for my professional email development portfolio.

As a freelance **Email Developer**, I build bulletproof, responsive transactional and campaign emails in HTML/CSS and MJML, with dynamic templating. I also look at the whole system behind an email, from your application's data through the template and your email platform to the inbox, so I can find where it breaks. I test across major email clients, including legacy desktop Outlook versions, with accessibility and deliverability in mind.

---

## 🛠️ Portfolio Site & Code Architecture

This portfolio website is custom-built from scratch to be lightweight, lightning-fast, and highly accessible without relying on heavy frontend frameworks:
* **HTML5 & CSS3:** Semantic markup, custom variables, CSS Grid, Flexbox, and responsive layouts.
* **Vanilla JavaScript:** DOM manipulation for mobile navigation, dark/light mode toggling, and image lightboxes.
* **SEO & Metadata:** Optimized with JSON-LD schema, Open Graph (OG) tags, and canonical routing.

---

## 📧 Core Email Development Expertise

My daily technical stack and capabilities include:
* **Custom HTML/CSS for Email:** Inline styles, VML, and ghost tables for Outlook compatibility.
* **MJML:** Rapid, robust, and responsive component-driven email development.
* **Handlebars and Liquid:** Dynamic personalisation and logic-driven templating for data-rich emails.
* **JavaScript and Node.js:** JSON payloads, ESP API sends, and the tests behind them.
* **API & data design:** Defining what data your application sends to your email platform: the JSON fields, the fallbacks, and the checks.
* **Troubleshooting the whole system:** Tracing a problem from your application's data to the template, the platform, and the inbox.
* **ESP integration:** Brevo, Mailchimp, Klaviyo, MailerLite, and Kit.
* **QA & testing:** Tested in real email clients and fixed before delivery.
