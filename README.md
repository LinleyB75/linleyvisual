This portfolio website is custom-built from scratch to be lightweight, lightning-fast, and highly accessible without relying on heavy frontend frameworks:

* **Vanilla JavaScript:** DOM manipulation for mobile navigation, dark/light mode toggling, and image lightboxes.
* **SEO & Metadata:** Optimized with JSON-LD schema, Open Graph (OG) tags, and canonical routing.
