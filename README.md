# linleyb.com

Website of Linley Bignoux: Business English and English for tech professionals.
One-to-one online lessons for developers and professionals in logistics, finance, sales and engineering.

Live site: https://linleyb.com

## Structure
- `index.html`: homepage
- `english-for-developers.html`: English for software developers
- `certifications.html`: teaching qualifications (images in `images/certificates/`)
- `blog/`: Business English at Work blog; old email-post addresses are redirect pages
- `privacy.html`, `thanks.html`, `404.html`
- `consent.js`, `mail-link.js`: cookie banner and email links
- `sitemap.xml`, `robots.txt`, `CNAME`

Hosted on GitHub Pages.
