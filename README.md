# Linley Bignoux | Email Developer Portfolio

**Email Developer / Front End Developer / Backend Integration** — HTML, CSS, MJML, Dynamic Content, Handlebars, Liquid, Node.js

The source of my portfolio site, [linleyb.com](https://linleyb.com/). I'm a freelance **Email Developer** in Mauritius, working with clients locally and worldwide.

I build transactional and campaign emails in HTML, CSS and MJML, with dynamic content in Handlebars and Liquid. I also look at the whole system behind an email, from your application's data through the email and your platform to the inbox, so I can find where it breaks. I test in major email clients, including older desktop Outlook versions, with accessibility and deliverability in mind.

---

## 🛠️ How the Site Is Built

The site is built by hand to be light and accessible, with no frontend framework:
* **HTML5 & CSS3:** semantic markup, custom properties, CSS Grid, Flexbox and layouts that adapt to the screen.
* **Vanilla JavaScript:** mobile navigation, dark/light mode, an image lightbox for certificates, the hero's drawn red system line, and a rotating case study button that pauses on hover and focus and respects reduced motion. Font Awesome supplies the icons.
* **SEO & Metadata:** JSON-LD structured data, Open Graph tags, canonical URLs and a sitemap.

## 📧 What I Work With

* **HTML, CSS and MJML:** inline styles, VML and ghost tables for Outlook, and MJML for component-based emails.
* **Handlebars and Liquid:** dynamic content and fallbacks for data-rich emails.
* **JavaScript and Node.js:** JSON params, ESP API sends and the tests behind them, including a Node.js reference for the send step.
* **API & data design:** defining what data your application sends to your email platform: the JSON fields, the fallbacks and the checks.
* **Troubleshooting the whole system:** tracing a problem from your application's data to the email, the platform and the inbox.
* **ESP integration:** Brevo, Mailchimp, Klaviyo, MailerLite and Kit.
* **QA & testing:** tested in real email clients and fixed before delivery.
