Frequently Asked Questions

What do these email dev notes cover?

Each note covers one real email rendering problem or technical topic: what happened, the cause (or that it isn't confirmed), the fix, and which clients I retested in. Some notes link to examples in my GitHub repository.

Do these notes cover dark mode and mobile rendering bugs?

Yes. Topics so far include macOS dark mode text colour, Apple data detector styling, dark mode colour inversion in Outlook, MJML column image spacing, and mobile column stacking. There is also a transactional email case study and a post on systems thinking.

Are the fixes tested in real email clients?

Each post says which clients I retested in. Some fixes were retested in only one client, so check the "What I retested" section and test in your own audience's clients before relying on a fix.

Can other developers and agencies use these notes for debugging?

Yes. They are written as practical references for developers, marketing teams and agencies facing similar cross-client rendering problems, but each fix should be tested in your own setup.
